# Python Scripts

Coleccion de scripts utiles en Python para automatizacion, procesamiento de datos y utilidades del dia a dia.

## Contenido

```
/file-tools     - Utilidades para manejo de archivos
/data-utils     - Procesamiento y transformacion de datos
/automation     - Scripts de automatizacion
/api-tools      - Herramientas para consumir APIs
```

## Requisitos

```bash
pip install -r requirements.txt
```

## Stack
- Python 3.10+
- requests, pandas, python-dotenv
